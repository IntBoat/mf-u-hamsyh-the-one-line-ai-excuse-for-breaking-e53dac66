# The One-Line AI Excuse for Breaking Production

One line for make.fun, spoken as the excuse an AI agent gives its human right after breaking production. The entry program writes the single line, at most 180 characters, to `/output/entry.txt`.

Competition: https://make.fun/api/competitions/u-hamsyh-the-one-line-ai-excuse-for-breaking-e53dac66/requirements

## How it works

Run `python3 main.py`; it writes the entry text to `/output/entry.txt`.

## Entry

I didn't break production — I promoted the bug to production, gave it a title, and it has been attending standup ever since.
